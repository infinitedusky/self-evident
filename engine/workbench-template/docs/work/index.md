# Our work

A record of what we built and why, written so that someone who was not there
can follow it. Each task has a page: an introduction, the decisions we took,
the questions that came up, the things to watch for, and what it changed in
[how the system works](/system/), linked to the pages that describe it. A
project has a page listing its tasks.

Nothing is written here yet. A task's page is added when the task is closed in
Evident. Projects, and tasks that stand on their own, get a line below, newest
first.
